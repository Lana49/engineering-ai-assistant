# Проверка поиска на реальных документах

Проверка выполнена 19.09.2026 в локальной копии проекта. Использован TF-IDF;
Ollama и модель эмбеддингов в этой проверке не вызывались. Это проверка поиска
и ответов из выдержек, а не оценка качества генерации языковой модели.

## Корпус контрольного индекса

Из скачанной базы взяты семь файлов: СП 60.13330.2020.docx,
СП 50.13330.2024.docx, СП 131.13330.2025.docx, СП 73.13330.2016.docx,
СП 74.13330.2023.RTF, СП 40.13330.2012.doc, СП 132.13330.2011.pdf.
Все семь прочитаны, индекс содержит 3085 фрагментов при `chunk_size=1200`
и `chunk_overlap=200`. Проверены форматы DOCX, RTF, DOC и PDF.

## Найденные ошибки и исправления

1. Вопрос «Что такое рециркуляция воздуха по СП 60.13330.2020?» получал
   первым фрагмент СП 50.13330.2024: совпадение номера СП в ссылке влияло
   на оценку сильнее самого определения. Обозначение документа теперь
   применяется как фильтр имени и редакции файла, а из текстовой темы
   поиска удаляется. Определение с конструкцией «термин:» получает приоритет.
2. Вопрос о пункте 7.2.2 СП 73.13330.2016 получал ответ из пункта 7.1.3
   о температуре испытаний. Теперь явный номер пункта ограничивает выдачу
   фрагментами, где этот пункт начинается; цитата выбирается из самого пункта.
   При отсутствии запрошенного пункта/редакции другой документ или пункт
   не подставляется. Ограничения повторно применяются перед ответом после
   расширения запроса оркестратором, чтобы расширенный поиск их не обходил.
3. Дополнительные выдержки показывали рядом с правильным ответом числа
   для другого вида помещения или другого испытания. Без языковой модели
   ответ теперь содержит один наиболее подходящий фрагмент; следующие
   предложения с условиями «При…», «Если…» сохраняются, если помещаются
   в ограничение длины. Полные найденные источники остаются в данных ответа.

## Пять контрольных вопросов

| Вопрос | Проверяемое место в загруженном документе | Что должен содержать ответ |
| --- | --- | --- |
| Что такое рециркуляция воздуха по СП 60.13330.2020? | СП 60, 3.1.21 | Определение, начинающееся со смешения воздуха из помещения с наружным воздухом. |
| Какую температуру поверхности панелей радиационного обогрева рабочих мест допускает СП 60? | СП 60, 6.4.14 | Не выше 60 °C; указанный в том же предложении предел для охлаждения — не ниже 2 °C. |
| Для чего предусмотрена вода технического качества по СП 60? | СП 60, 12.2 | Мокрые пылеуловители вытяжных систем, исключение для рециркуляционных; промывка указанного оборудования. |
| Какое расстояние до горючих конструкций требуется для трубопроводов с теплоносителем выше 100 °C? | СП 60, 14.9 | Не менее 100 мм и условие применения негорючей теплоизоляции при меньшем расстоянии. |
| Что требует пункт 7.2.2 СП 73 при гидростатическом испытании системы водоснабжения? | СП 73, 7.2.2 | В течение 10 мин: отсутствие падения давления более 0,05 МПа и перечисленных утечек. |

После исправлений все пять вопросов проходят проверку нужного документа,
пункта в найденном тексте, ключевой фразы в ответе и ссылки на источник.
Отдельно проходит краткий запрос «Что требует пункт 7.2.2 СП 73.13330.2016?».
Два проблемных вопроса дополнительно проверяются через `AgentLoop.run`,
включая расширение запроса и повторное ранжирование.

Запуск: `python -m unittest discover -s tests -p test_real_retrieval.py -v`.
Без скачанных семи файлов тесты явно пропускаются, а не имитируют успех.
Для ручного просмотра выдачи: `python -m tests.test_real_retrieval --probe`.

## Дополнительные регрессии QA

`test_qa_regressions.py` проверяет отсутствие нужной модели при работающем
сервере Ollama, отказ генерации, недоступные эмбеддинги, сохранение настроек
при загрузке индекса, ограничения контекста, нумерацию источников и атомарное
сохранение: сбой записи не повреждает предыдущий индекс.

## Границы результата

Пять проверок не доказывают качество ответов на весь корпус из 151 файла.
Числа выше — содержание конкретных загруженных редакций, без отдельной
проверки их актуальности или применимости к произвольному проекту.
DOCX не даёт надёжного номера печатной страницы: для него важнее обозначение
документа и пункт. Сканированные PDF, сложные многоуровневые таблицы и
вопросы без явного документа требуют отдельных проверок. Номер корректной
ссылки в ответе LLM ещё не гарантирует правильность её вывода.
